# 崩溃日志

用于定位闪退原因的本机日志，入口：**我的 → 崩溃日志**（有记录时标题显示数量）。

## 记录内容

- **未捕获异常**（NSException）：异常名、原因、完整调用栈。
- **信号崩溃**（SIGABRT / SIGSEGV / SIGBUS / SIGILL / SIGFPE / SIGTRAP）：
  信号号 + 崩溃前的操作记录。信号处理里只做异步信号安全的文件读写，
  所以没有调用栈；需要完整栈时可查 iOS「设置 → 隐私与安全性 → 分析与改进 → 分析数据」
  里本 App 的 `.ips` 日志。
- **上次会话异常结束**：启动时发现上次没有正常进入后台（session 标记残留），
  补一条「上次会话异常结束」记录并附最近操作，覆盖未捕获异常之外的闪退/强杀。
- **最近操作（面包屑）**：启动、打开书籍、进入漫画阅读、漫画章节加载/失败、
  图片加载失败、目录刷新与跳转等关键节点，带时间戳。

## 使用

- 列表页：点开单条查看全文（可选中复制），右上角可复制 / 分享（.txt）。
- 底部：复制全部 / 分享全部 / 清空。
- 只保存在本机 `Application Support/LegadoReading/crashes/`，最多保留 20 条。
