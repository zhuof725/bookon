# 统计页（阅读目标）

统计页按参考设计重做成一整页「阅读目标」：页头日期 + 四张卡片 + 三个分区，全部使用
App 主题的 `palette.surface / primary / secondary`，默认主题下就是白卡片、浅灰底。

## 数据从哪来

| 卡片 | 数据源 | 文件 |
| --- | --- | --- |
| 今日阅读 | 阅读会话（`ReadingStatsStore`）+ 听书秒数（`ListeningStatsStore`） | `Application Support/LegadoReading/sessions.json`、`listening.json` |
| 连续阅读 | 上面两者按天取并集；阅读当天或听书 ≥30 秒都算 | 同上 |
| 今年已读 | `FinishedBookStore` 记的读完时间按月分桶 | `finished.json` |
| 阅读计划 | `ReadingPlanStore` | `plans.json` |
| 阅读统计 | 近 7 / 30 天的分日阅读与听书时长 | 同第一行 |

- 阅读会话仍是「打开阅读器 → 离开」的区间，不足 3 秒不记。
- 听书时长由播放器按真实播放进度累计：有声书每次进度回调只加 0.5 秒级的增量，
  朗读（TTS）在播放中每秒加 1 秒；暂停、缓冲、拖进度条都不会跳增。
- 目标值放在 UserDefaults：`reading.goal.dailyMinutes.v1`（默认 15 分钟）、
  `reading.goal.yearlyBooks.v1`（默认 12 本），视图用 `@AppStorage` 直接读写。

## 连续阅读与热力图

- 网格列 = 周（周一开头），行 = 周一…周日，最后一列是本周，共 18 周。
- 格子深浅按「当天时长 ÷ 每日目标」分 5 档：无记录、<25%、<50%、<100%、≥100%。
- 今天那格额外描 1.5pt 黑边。
- 今天还没读时，「当前连续」不会在零点归零：从昨天往前数，直到断档。

## 今年已读

- 「读到最后一章末尾会自动记为读完」：分页模式在最后一章再往后翻时，
  `goAcrossEdge` 会调用 `FinishedBookStore.mark(book)`。
- 手动标记在两处：书架长按菜单（网格/列表都有）、统计页「今年已读」右上角
  「标记读完…」列表。
- 重新打开一本已读完的书不会取消记录；要取消在同一个菜单里点「取消读完」。
- 没有读完记录时，柱状图显示 12 根虚线示意柱（和参考图一致）；有记录就换成实心柱。

## 阅读计划

- 三种节奏：按日期读完 / 每天几章 / 每天几分钟。
- 剩余章节数来自目录缓存 `AppStore.cachedToc`（打开过书籍才有），没有缓存时只显示节奏本身。
- 打卡：阅读器关闭、统计页出现时都会用当天该书的阅读会话判断是否达成；达成写入
  `checkedDays`（按 `yyyy-MM-dd`）。
- 提醒：创建计划时可选每天固定时间提醒，用 `UNCalendarNotificationTrigger` 重复通知；
  第一次创建才申请通知权限，拒绝不影响计划本身。删除计划会取消对应通知。
- 计划卡片显示节奏摘要、最近 7 天打卡格、今天已读分钟数。

## 代码位置

- `Sources/Engine/ReadingGoals.swift`：目标键、听书存储、连续天数、热力图、读完的书、阅读计划。
- `Sources/Engine/ReadingStats.swift`：原有会话统计 + 统计页需要的分日数据。
- `Sources/App/StatisticsScreen.swift`：页面、卡片、环形进度、热力图、两张图表、分段控件。
- `Sources/App/ReadingGoalSheets.swift`：每日/年度目标、标记读完、新建计划、计划卡片、通知。
- 听书计时的接入点：`BookAudioPlayer.startTimeObserver`、`ReaderAloud.restartListeningClock`。
