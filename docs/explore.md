# 探索（自定义分类板块）

底栏新增「探索」，原来的「统计」移进「我的 → 阅读统计」。探索页是一张可自由拼装的发现页：
每张卡片 = 一个（或几个）书源的发现分类 + 一种参考版式。

## 六种版式

| 版式 | 参考图 | 数据 | 说明 |
| --- | --- | --- | --- |
| 畅销精选 `bestseller` | 神的模仿犯那张 | 第一个分类 | 大封面列表：书名、两行简介、`分类 · 字数`、右侧标签（第一个暖色） |
| 品质好书 `coverGrid` | 成龙快婿四列封面 | 第一个分类 | 四列封面，书名两行 + 分类 |
| 双列榜单 `rankColumns` | 穿越榜/系统流榜 | 全部分类作顶部标签 | 双列 10 名，前三名暖红圆角序号 |
| 新书榜 `newBookRank` | 新书榜 + 筛选胶囊 | 全部分类作筛选胶囊 | 标题旁副标题、带小封面与徽标的双列榜单 |
| 分类推荐 `categoryFeed` | 轻小说/奇幻/仙侠 | 全部分类作顶部标签 | 标题下一条灰色推荐语，双列书单 |
| 猜你喜欢 `forYou` | 猜你喜欢 | 第一个分类 | 每本书一张卡：推荐理由 + × 关闭（按板块记住隐藏） |

带标签的三种版式（双列榜单 / 新书榜 / 分类推荐）把第 2 个起的分类显示为顶部标签或胶囊；
其余版式只用第一个分类。

## 配置

- 入口：探索页右上角「管理」菜单 →「添加板块 / 管理板块 / 刷新全部 / 导入标签」。
- 添加板块：选书源 → 勾选该书的发现分类（可多选，支持全选）→ 选版式 → 标题（留空跟随第一个分类名）。
- 勾「每个分类各建一个板块」会按分类名自动挑版式，一次把整个书源铺成一页。
- 长按卡片可编辑 / 删除；「管理板块」里可拖动排序、左滑删除。
- 配置存在 `UserDefaults["explore.boards.v1"]`（一段 JSON），顺序就是页面顺序。
- 书单复用发现页缓存（`DiscoverBlockCache`，有效期跟随「发现设置」里的缓存天数）；
  请求并发和发现页共用 `BlockRequestGate`。

## 标签与推荐语（AI 接入点）

`Book` 只有书名、作者、简介、分类、字数，没有标签和推荐理由。这两类内容由外部写入：

- 文件：`Application Support/LegadoReading/explore-meta.json`
- 结构：

```json
{
  "https://example.com/book/1": {
    "tags": ["求生游戏", "悬疑流", "游戏异界"],
    "reason": "这本「都市异能」佳作与你的匹配度高达 87%！",
    "updatedAt": "2026-10-25T04:00:00Z"
  }
}
```

- App 内入口：探索页「管理 → 导入标签 / 推荐语…」，粘贴上面的 JSON 即可（也接受
  `{"书籍地址": ["标签", "标签"]}` 的简写）。
- 代码入口：`ExploreMetaStore.setTags(_:for:)` / `setReason(_:for:)` / `merge(json:)`。
- 展示规则：
  - 标签：每本书自己的标签优先；没有时用板块里填的兜底标签；都没有就不显示。
  - 推荐语：`reason` 里有 `“…”`、`「…」`、`『…』` 时，引号里的片段用蓝色高亮（对应参考图）。
  - 没有 `reason` 时按书的分类拼一句「这本「都市」佳作，也许正合你口味」，保证卡片不空。

## 文件

- `Sources/Engine/ExploreBoard.swift`：版式枚举、板块/分类模型、编解码容错、字数/标签整理、版式猜测。
- `Sources/Engine/ExploreMeta.swift`：标签/推荐语存储与 JSON 合并、推荐语高亮切分。
- `Sources/App/ExploreStore.swift`：板块配置 + 分类书单加载（缓存 / 并发闸门）。
- `Sources/App/ExploreAtoms.swift`：卡片、页头、标签胶囊、排名、封面、推荐语等共用件。
- `Sources/App/ExploreBlocks.swift`：六种版式。
- `Sources/App/ExploreView.swift`：探索页、管理面板、标签导入面板。
- `Sources/App/ExploreEditor.swift`：板块编辑、书源选择、分类多选。
- `Tools/SourceTest/ExploreBoardRegression.swift`：离线回归（版式猜测、标题回退、编解码、字数、标签、推荐语高亮、落盘、AI 合并）。
