# Independent glass cards and live previews

- ThemeLaunchOverlay has no Skip button. The overlay itself dismisses after 1.2 seconds, including VoiceOver and full-screen editor preview; the production session claim remains once per process. Accessibility escape remains available. No system LaunchScreen change.
- Shared independentGlassRow adds separated round glass backgrounds and removes row separators in search/history, source management/login, reader settings/TOC/search, detail categories/TOC/sources and rule editors. TOC rules, body rules, font faces and appearance choice rows now have individual surfaces rather than a single group plate. Profile/statistics/shelf/detail/cache already use isolated cards. Source debug inputs/results and reader loading/retry panels also adopt glass. Real covers, reader paper/content, color swatches, native system controls/dialogs and web content are not wrapped as fake cards. Explicit saved content-card transparency/opaque/off choices remain available; this change never overwrites a saved theme.
- ThemeSettingPreview is pinned above every customization subpage: actual native TabView on iOS26 (legacy LibraryDock otherwise), cover loader and clamped shelf columns/width, fallback cover crop, launch-image framing, live palette/font/canvas, blur/glow/tint and card radius/border/background. Changes resolve from the editor draft and do not apply/save it. Preview sample data never enters the shelf. Large accessibility text uses a compact preview height and scrollable settings.
- Reader settings also have a real TextKit paragraph preview for font/size/spacing/margins/paper/justification. This is explicitly a scroll sample, not a simulated complete bottom-justified page or a page-turn-animation preview; no pagination/progress code changes. Reader settings still save immediately as before, unlike theme editor drafts.
- Glass uses iOS26 regular Liquid Glass with older-system material fallback and solid Reduce Transparency fallback. Existing wallpaper, icon import and no fake reference-feature contracts remain unchanged.
- Native focused tests: eight preview routes and live draft summaries, splash absent Skip + automatic repeat preview close, real List callbacks, settings dark320, TOC static and native glass pixel assertions. Tests use isolated offline fixtures; not all app/network paths are end-to-end exercised.
