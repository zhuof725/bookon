# 发现（书源浏览）

底栏新增「发现」标签（书架 / 发现 / 统计 / 我的 + 搜索），直接浏览书源的发现内容（不再按分组分级）。

## 结构

1. **书源**：可发现的书源平铺在发现页（首字头像、名称、类型标签、域名），网格/列表两种排法由右上角菜单切换。
2. **书源的发现页**：左上角是「登录」「分类」两个按钮 —— 配了登录的书源才显示「登录」，没配登录的只显示「分类」。
3. **分类**：点进书源后读取它的发现规则（`exploreUrl`，支持 `@js:` / `<js>`）；规则里没有网址的项作为小节标题（对应原版的 flexGroup 分组，如「推荐」「最热」「最新」），其余为可点分类。脚本失败时显示错误并可重试。
4. **分类筛选面板**（左上角「分类」打开）：标题「分类筛选」+ 副标题「选择想看的分类」+ 分类标签搜索框 +
   「快捷操作」（搜索：按关键词走书源搜索规则；刷新：重读分类；登录：打开书源登录面板）+ 分类标签网格（4 列）。
   点标签即选中：杂志布局滚到对应板块，列表布局切到该分类的书单。
5. **书单**：点进分类后加载书籍列表（`ruleExplore`，缺省回退搜索规则）；分类地址含 `{{page}}` 时底部提供「加载更多」，翻页按 `bookUrl` 去重；点书籍进入原有详情页。

## 参与条件

- 书源启用（`enabled`）且「启用发现」（`enabledExplore`，缺省开启）
- 配置了非空的 `exploreUrl`

## 入口与显示顺序

`LibraryTab.discover`（rawValue 固定为 4，不影响已存序号）；显示顺序由 `LibraryTab.displayOrder` 决定，搜索固定在底栏最右。iOS 26 使用系统 TabView，旧版 iOS 使用 `LibraryDock`。

## 代码

- 整理逻辑：`Sources/Engine/DiscoverCatalog.swift`（过滤、分组、域名、分类切节、头像色）
- 界面：`Sources/App/DiscoverView.swift`（发现 → 书源 → 分类 → 书单）
- 分类筛选面板：`Sources/App/DiscoverCategorySheet.swift`
- 回归：`Tools/SourceTest/DiscoverRegression.swift`（离线夹具：武芊漫画的 77 项发现分类与 4 段切节）
