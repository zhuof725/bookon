# 音频书源（有声书）

支持 legado 的音频书源（`bookSourceType == 1`，例如「喜马拉雅（优+）」）：
打开这类书籍的章节时，阅读区直接进入音频播放界面，而不是把音频地址当正文排版。

## 识别规则

- 书源「类型」为音频（编辑书源里可设置），或章节地址本身是音频直链
  （`.mp3/.m4a/.aac/.wav/.flac/.ogg/.m4b/.opus/.wma/.amr`，忽略查询参数与锚点）。
- 音频章节不抓正文、不写正文缓存：`ChapterContentLoader` 直接返回章节地址，
  阅读器据此走播放而不是文字排版（预读也因此不会把音频文件当正文下载）。
- 目录、搜索、详情仍走书源自己的规则，例如喜马拉雅源的
  `chapterUrl = playPathAacv224||…` 会按候选顺序取第一个非空地址，
  `nextTocUrl` 返回多页地址时按页抓取；多页目录按小并发（4 页一批）
  抓取并保持页序，避免一次 8、9 页串行等待。

## 播放

- AVPlayer 流式播放；播完自动进下一章；锁屏控制台支持 播放/暂停/上一章/下一章。
- 阅读页底栏喇叭按钮在音频章节控制 播放/暂停（不再进文字朗读面板）。
- 界面与听书播放器同一套：顶栏返回胶囊 + •••（目录/停止播放）、书名/作者、
  「第 N 章」+「N / 总章数 章」、大封面（右下角「播放中 / 已暂停」）、
  当前章节 + 「下一章 · xxx」，进度条，⏮ / 后退 15 秒 / 播放 / 前进 15 秒 / ⏭，
  底栏玻璃胶囊（目录 / 倍速 / 定时 / 设置）。
- 进度滑杆拖动时只跟手指、松手才定位，等播放器真正到位再交还真实进度（不回弹）；
  ±15 秒是真正的音频时间跳转，倍速 0.75–2.0
  （`AVPlayerItem.audioTimePitchAlgorithm = .spectral`，变速保持音调；
  更快倍速请改用文字朗读的听书倍速）。
- 缓冲/失败会显示在「下一章」那一行；来电、拔耳机自动暂停（可恢复时自动续播）。
- 章节内位置不跨次保存（只记章）：再次打开从本章开头继续。

## 已知边界

- 一章对应一个音频地址；「正文规则返回多个音频片段」的源只取章节直链。
- 需要付费/签名的音频能否播放取决于服务端（如喜马拉雅的 `buy_key` 过期会失败）。
- 音频书不走正文替换、段评等文字排版功能。
